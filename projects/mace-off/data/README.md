# Local data

Place licensed SPICE inputs and generated TorsionDrive references here. Data is
ignored by Git and is not included in this project folder.

Required inputs for the torsion workflow:

- `TNet500_minimal/*.json`
- `biaryl_minimal/*.json`

The SPICE force-evaluation scripts also use `test_large_neut_all.xyz` and, for
training-related workflows, `train_large_neut_no_bad_clean.xyz`.
