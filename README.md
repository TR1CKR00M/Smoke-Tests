# Smoke Tests: reproducible research workspace

This repository is a long-lived workspace for reproducible data-to-paper workflows. Each project is isolated with its own data, configuration, code, outputs, and tests.

| Project | Goal | Status |
| --- | --- | --- |
See [`projects/README.md`](projects/README.md) for the current project registry.

## End-to-end reproduction

```bash
uv sync --extra dev
make test
make lint
```

Project-specific commands write raw outputs, processed metrics, manifests, figures, and reports under the relevant project's `results/` folder.

## Repository layout

```text
projects/
  <project>/
    README.md
    configs/
    data/raw/
    src/<package>/
    results/{raw,processed,figures,reports}
    tests/
src/common/
docs/
```

Each project has its own README. The top-level docs define the architecture, provenance policy, reproduction guidance, and governance standards.

## Provenance chain

`data/raw` → validation and cleaning → model/reference evaluation → raw results → processed metrics → figures → reports.

Each project keeps its own manifest with SHA-256 hashes, row counts, split parameters, and runtime metadata. Processed files are generated by the pipeline and can be removed and regenerated at any time.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). New experiments should get a new folder under `projects/` with their own data, config, code, tests, outputs, and report.
