# Reproducing everything

## 1. Environment

```bash
uv sync --extra dev
```

This creates `.venv/` and installs the pinned dependency ranges recorded in `uv.lock`.

## 2. Run both experiments

```bash
make reproduce
```

Equivalent individual commands:

```bash
uv run python -m house_prices_shap.pipeline \
  --config projects/house_prices_shap/configs/experiment.yaml
uv run python -m jarvis_volume.pipeline \
  --config projects/jarvis_volume/configs/experiment.yaml
```

The SHAP step is optional for a faster smoke run:

```bash
uv run python -m house_prices_shap.pipeline \
  --config projects/house_prices_shap/configs/experiment.yaml \
  --skip-shap
```

## 3. Validate

```bash
make test
make lint
```

CI runs the fast tests and lint on every pull request.
